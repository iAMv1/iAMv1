# iAMv1 Automation Hub

Autonomous repository agent powered by Gemini + GitHub Actions.

## Stack
- **Runtime**: GitHub Actions (self-hosted runner coming)
- **Brain**: Google Gemini 2.0 Flash (free tier)
- **Tools**: gh CLI, MCP, agent-reach
- **Protocol**: MCP (Model Context Protocol)

## Agents
- `ARA` — Autonomous Repository Agent (runs every 6h)

## Vision
This repo is the control plane for autonomous repository management.
Agents monitor, triage, report, and evolve — without human prompting.
